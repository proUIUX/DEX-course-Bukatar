# Смета

Статус раздела: актуально

## Зачем
- Быстро дать заказчику примерную стоимость ремонта.
- Подготовить смету для договора и не потратить полвечера.
- Не создавать смету с нуля: шаблоны, калькулятор, импорт из Excel, цены Петровича.

## Кто пользуется
- Исполнитель: создаёт и редактирует, задаёт наценку, делится, скачивает PDF и Excel.
- Заказчик: видит позиции и итог без себестоимости и наценки, может купить материалы.
