# Анимации

## Общие правила
- Анимации интерфейса собираются кодом из реальных экранов, не видео. Экран берём из макета Figma как есть.
- Каждая сцена: курсор, клики с кольцом, подписи шагов сверху («1 Создайте объект»), камера приближается к курсору.
- Сцена работает, только когда видна на экране. После прохода сообщает лендингу, и тот переключает вкладку.
- Длительности интерфейса: появление 250-500 мс, ease-out. Курсор 0,6-1 с на переход. Пауза на результате 1,5-3 с.
- Появление блоков при прокрутке: сдвиг 24px и прозрачность, 0,7 с.
- При системной настройке «уменьшить движение» показываем финальный кадр сцены без анимации.
- Движок: `landing-motion/bro-ui.js` (`UI.scene`), параметры `?state=N` (статичный кадр), `?once`, `?zoom`.

## Шаблон описания сцены
Скопируйте блок для каждой вкладки и заполните.

```
### <id сцены>
- Где: карточка <…>, вкладка <…>
- Цель: что пользователь должен понять
- Экраны (Figma): шаг 1 <ссылка>, шаг 2 <ссылка>, …
- Шаги:
  1. Экран <…>. Курсор <куда>. Действие <клик, ввод «…»>. Результат <что меняется>
  2. …
- Подписи: «1 …», «2 …»
- Плашки поверх: <текст, когда появляется>
- Длительность: <секунд>, повтор: да/нет
- Финальный кадр (для reduced motion): <шаг>
```

## Пример заполнения
### estimate-template (черновик для правки)
- Где: «Смета за пару кликов», вкладка «Шаблоны».
- Цель: смета собирается из шаблона за пару кликов, цены подтягиваются сами.
- Экраны: 2739:25744 (создание объекта), 2739:23561 (системный шаблон), 3177:49791 (смета).
- Шаги:
  1. Экран создания. Курсор в «Название объекта», ввод «Квартира на Пушкинской».
  2. Выбор «Смета из шаблона», список системных шаблонов, клик «Ванная под ключ».
  3. Клик «Создать смету и объект». Переход к смете, строки появляются, итог досчитывается.
- Подписи: «1 Создайте объект», «2 Выберите шаблон», «3 Смета готова».
- Плашки: «Шаблон выбран, системный, 20 позиций», «Цены Петровича подтянулись сами».
