# Компоненты

Правило: если компонент есть в ките, используем его. Самодельные кнопки, иконки и поля не рисуем.

## Кнопки
- Набор `Button`, ключ `bb69074ae8fc175104c6d39ab9db34b977164e3d`.
- На лендинге: `radius=square` (r8), как в продукте. Круглые (`circle`) не используем.
- Размеры: `md` 48 (шапка), `lg` 64 (hero, CTA).
- Типы: `primary` (жёлтая, главное действие), `default` (серая, второстепенное). На тёплом фоне кнопка `default` с белой заливкой.
- Иконки в кнопках по умолчанию выключены (`icon start`, `icon end`).
